UNO · COSTUME CHAOS

🎭 越输越离谱

四人奇装异服冠军赛。输了叠装备，赢了卸装备。搞笑社死 + 微辣台词 + 复仇换装。

👥 4人⏱ 2–3小时🎁 20件装备🚫 不赌钱、不脱衣
📖 游戏规则（开局前读一下）
  1. 按正常 UNO 出牌；最先出完牌的是赢家，其他三人中剩余手牌分值最多的是输家。数字牌按点数、功能牌20分、万能牌50分；若最高分相同，比较剩余张数，仍相同则抽签。
  2. 输家抽一件装备穿戴；赢家从自己身上卸下一件装备，如果身上没有装备则获得1张免罚券（最多持有1张）。
  3. 输家如有免罚券，自动消耗1张并免抽装备。每人最多同时戴3件；第4次增加装备时，替换一件旧装备，另外表演10秒钟新装备登场。
  4. 装备自带台词/搞笑任务，只作为互动，不改变 UNO 出牌规则；同一装备每局最多触发一次。没有实物可以用纸条、胸牌或替代道具表示。
  5. 每局赢家+2积分、输家-1积分。第5、10局结束后，赢家可指定两位有装备的玩家互换各一件装备（也可放弃）。第15局结束后全员参加10秒角色展示。建议打15–18局，最后按积分评冠军。
  6. 不碰触他人、不脱正常衣物、不强迫揭隐私。任何不舒服的装备或台词都可以无条件跳过、更换，不需要解释。
