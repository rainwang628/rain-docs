账号与权限

博客公开浏览。登录后申请模块访问，网站主人确认后开放指定功能。

初始化模块权限

网站主人需在现有 Supabase 项目的 SQL Editor 执行一次下方脚本。它建立分类与模块权限，不重建用户，不清空购买记录。

登录后点击“复制当前账号的初始化 SQL”，在 SQL Editor 中粘贴执行。也可打开模板，把 __OWNER_EMAIL__ 替换为自己的已确认网站邮箱。
