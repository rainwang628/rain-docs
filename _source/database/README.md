# 数据库脚本与配置

这里按模块保存网站使用的 SQL 和配置说明。脚本是维护资料，不会因移动目录而自动执行。

| 目录 | 内容 |
| --- | --- |
| `website/` | 网站账号、模块权限与文章分类管理 |
| `usd/` | 美元购汇记录的数据库脚本和配置说明 |
| `nutrition/` | 饮食管理、食物明细脚本和配置说明 |
| `surveys/` | 活动问卷、夫妻问卷访问与修改、删除问卷 |
| `stories/` | 故事删除请求队列 |

网站会把账号、购汇和活动问卷使用的初始化脚本生成为 `assets/sql/` 下的公开副本，网页引用也指向这里；旧的根目录 SQL 直链已变更。需要修改脚本时，以本目录为准，再运行 `python3 _source/publish.py` 生成副本。执行 SQL 前应先核对现有数据库状态；已有数据不应因整理目录而被重建。
